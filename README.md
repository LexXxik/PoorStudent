# PoorStudent
### video demonstration: https://youtu.be/cqkJaPvkxag

## Project Description (What the project is?)

This project is a Flask based webscarpping app. After opening the website user can write a list of items which they intend to buy. They can also specify
the number of items and category. After they click search button PoorStudent determines where user should go shopping, so the list is the
cheepest. The server opens website of Morrisons and Asda where it searches for the items and chooses ones with the lowest price. Finally,
a table of results, which contains quantity, search item, result name, price and item image, is displayed. The name of the shop is shown as
well.

The program was run and tested using debugger mode of Visual Studio 2019.

## Setting up the project

In the project directory there is an empty folder called 'GoogleChromePortable'. To this folder chrome portable should be installed and chrome
geckodriver moved before the project is run. For testing purposes version 93.0.4577.82 of chrome portable was used, with corresponding gecko
driver. I found them at:

chrome portable: https://portableapps.com/news/2021-08-31--google-chrome-portable-93.0.4577.63-released
gecko driver: https://chromedriver.storage.googleapis.com/index.html?path=93.0.4577.63/

## Files in the project (What each of the files contains and does?)
### project directory

***app.py***
This file is the main file of the project. It takes care of managing GET and POST requests with Flask. It also gets data from JavaScript
part of the project and it calls functions in webscrape.py.

***FlaskWebProject1.pyproj and FlaskWebProject1.pyproj.user***
These files were used to launch the project in Visual Studio 2019.

***predefined.py***
It contains all hard-coded data in the project such as categories of food, array of stores including their URLs.

***requirements.py***
It contains names and versions of packages used in the project.

***webscrape.py***
This file contains functions which take care of finding URLs of items, opening them with selenium, scraping html content, filtering html content,
finding the cheepest item, comparing lists of items between shops.

### templates directory

***item.txt***
This file contains html code of one item from the list of form at shopping.html.

***layout.html***
This file defines common layout of all html pages in templates.

***results.html***

## Design choices (What choices did you make?)

I watched a few videos on webscrapping with beautiful soup and I was facinated by the concept, so I have decided to do this project.
I used Flask framework, because we we worked with it in the course. First, I started with shopping.html and listing.js since I wanted the
app to look nice. However, it took me a few days to figure out how to properly generated dynamical form. I also wanted to experiment with 
other html packages so that is why I have included animated text. 

Afterwards, I moved to app.py. My first big issue was to figure out how to tell python the number of input fields generated by listing.js.
That is when I became familiar with passing variables from front-end to back-end. Then, I though that I just need to generate URL for each
item and scrape it with beutiful soup, but it turned out that all the sites I had chosen were generated dynamically. Urlib and request libraries
did not wait till the dynamical content is generated, so beutifulSoup scraped scripts instead of actual html content. 
That is when I had to look at  Selenium and using ChromePortable. It turned out that it took much longer to load website than with other
libraries, but I did not have any other option. This I think is the biggest drawback of the project.

Sorting out above problem took a few more days of work, so at this point I wanted to finish it. As you may notice in app.py I am using global
variables to store the list inputed by user. I did not test it, but I think that for this reason PoorStudent could be used by only one user
at a time, since more users can creat a conflicting content of these global variables. I could solve it by passing list using URLs as I did 
from listing.js to app.py, but as I said at this point the project was becomming more and more complicated.

Finally, I have written current version of results.html to test output of webscrape.py. I thought that it might be useful for user to see
what items they should look at store, so I have included images as well. Then I polished some obvious bugs and recorded the video you have 
probably seen.

All in all, this project taught be a lot about webscrapping as well as how to overcome technical difficulties. I recon that delay between
input and search is pretty long, but to sort it out the databases would have to be used. For a while I was thinking about implementing it. 
First, PoorStudent would look whether items are in the database and if they are missing only then it would proceed to webscraping. I could
also write update function which would look at the inputs already in database and update prices if required. I think it would increase
deployability of the project. However, I think that it is good at this stage as a final project for CS50, so I am uploading it. Finally,
I want to thank you for the course, I felt like I am studying at Harvard and it was an amazing experience. I will for sure
look at other CS courses, specifically artificial intelligence.
